# STARKER SINUCA V1.6

Atualize index.html, server.js e physics.js juntos no GitHub e publique no Render. A física compartilhada roda localmente a 60 passos/s, com interpolação entre passos. O servidor continua validando as tacadas e decidindo o resultado. O atrito inclui desaceleração constante para reduzir o movimento residual. Música, efeitos, modalidades e salas preservados. Sem banco de dados.

Executar: npm install && npm start.
Testar física: npm test.
